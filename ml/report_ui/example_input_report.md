# Báo cáo marketing — phân tích lan truyền

### 1. Khả năng lan truyền
Bài đăng này **có khả năng lan truyền** (xác suất ước tính: **67%**, độ tin cậy của mô hình: 34%).

### 2. Lý do chính
- **Post content/topic** làm tăng điểm.
- **Topic #6** làm tăng điểm.
- **Ratio of opening hook** làm tăng điểm.

### 3. Gợi ý cải thiện
- Add a clear call to action (CTA).
- Add concrete numbers or proof.
